# Revised prompts, Core Set II

Prompts revised during the Core Set II art review, for folding back into the art bible. Each `<card id>.txt` is the full prompt that produced the current art; each `.diff` compares it with the original prompt, split at commas for readability. Cards revised only to pass the output filter (Lamia, Moon-Palace Kitten, Styx Shade) have no diff.

`cs2-jiuwei.txt` is the prompt behind Jiuwei v2. That image was generated with a nine-tail reference sketch attached; `cs2-jiuwei.v2-request.txt` is the full request sent to Codex, including how the reference was used.
