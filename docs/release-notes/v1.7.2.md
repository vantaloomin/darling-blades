A small patch for one report from the first evening on 1.7.1: the new
Hauntlink window could trap you in combat.

**Pass (Hauntlink) works again.** When a Hauntlink permanent could be moved at
the combat damage step, the game opened its window and offered a Pass button
that did nothing, so the duel could not continue. The button, and the Space
and Enter shortcuts behind it, now pass the window as they should.

**Links can move inside the window.** The same window exists so a Hauntlink
permanent can jump to a new host before damage or a trigger lands. Clicking a
Hauntlink permanent to link or move it now works in every Charm-speed window,
not only during your own main phase, which is where it had been limited to
before.

Nothing else changes: the rules, the cards, and the AI are the same as 1.7.1.
